## Phase Goal

**As a** team member tracking time, **I want to** turn one or several meeting suggestions into time entries on a project in a single action, **so that** logging meeting time takes one click instead of re-typing it from Outlook.

<objective>
Browser proof of the whole Phase 4 UI in CI, where the Microsoft integration is off: meetings are injected through the test hook with actions enabled, the convert request is fulfilled by `page.route()` which creates the real entry through the core API, and the spec checks the single form, every entry point, multi-select, batch results with a failure and a retry, and the UI-SPEC overflow backstops. Then the wave-3 CI gate (this plan is the anchor).

Purpose: the UI half of ASGN-01..05 proven in a real browser instead of manual UAT (owner preference); server behaviour stays proven by PHPUnit (04-01, 04-02).
Output: `e2e/outlook-convert.spec.ts`; Playwright and NPM workflows green for the merged wave-3 sha.
</objective>
