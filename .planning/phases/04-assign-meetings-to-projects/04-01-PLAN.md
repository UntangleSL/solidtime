## Phase Goal

**As a** team member tracking time, **I want to** turn one or several meeting suggestions into time entries on a project in a single action, **so that** logging meeting time takes one click instead of re-typing it from Outlook.

<objective>
Server side of a single conversion, end to end: a fork link table, a convert endpoint that runs the core create action in-process inside one transaction with the link insert, per-meeting results with mapped errors, the read side that hides converted meetings, the convert URL in the calendar prop, and every Phase 4 string in English and Spanish.

</objective>
