## Phase Goal

**As a** team member, **I want** a calendar that is easier to read and move around (view options, readable meeting blocks, hover details, smooth zoom and scroll), **so that** working with time entries and Outlook meetings feels as fluid as in Clockify.

<objective>
UX-04 seam and menu (D-06) plus the D-04 header legend: a right-click on a meeting gets its own menu through one additive core slot (`context-menu-overlay`) and an overlay branch in `useContextMenu` (03.1-RESEARCH Pattern 5, 03.1-UI-SPEC section 4); the core also hands `contextMenuOpen` and `interacting` to the fork layer so 03.1-05 can close hover cards and panels first; and the day headers get the "My time | Outlook" caption through a `day-header-extra` slot (UI-SPEC "Zone cues" 3).

Purpose: the empty-slot menu never appears on a meeting, the menu can never end up under a panel (single core menu flag), and the Outlook side of each day is labelled.
Output: core seams (ledgered), two fork components with Vitest proof, CI fast gate.
</objective>

Data safety: nothing in the meeting menu may create, change or delete a time entry.

Parallel waves (owner, 2026-11-10): plans of one wave have disjoint `files_modified` and may run at the same time in separate worktrees. Never edit a file owned by a same-wave sibling plan (here: OutlookGhostLayer.*, OutlookGhostDetail.*, OutlookMeetingSummary.*, OutlookMeetingHoverCard.* belong to 03.1-05); if one of its tests breaks because of this plan, report it instead.

Push protocol (once per plan, in its last task): `git pull --rebase origin feature/m365-integration && git push origin HEAD:feature/m365-integration`. On a non-fast-forward rejection run both commands once more; a second rejection or a rebase conflict stops the plan and is reported.

CI batching (owner): each plan runs the local gates, pushes, then waits in the background for the fast workflows on its own HEAD (Gate W). Same-wave plans wait at the same time, so a wave costs one CI cycle. Playwright is NOT awaited here; the browser proof of this menu is 03.1-07.
