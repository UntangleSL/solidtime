## Sampling Rate

- **After every task commit:** the task's `<verify><automated>` (Vitest of the touched area + vue-tsc; tsc where noted)
- **After every plan:** Gate F locally, push, Gate W on the plan's own HEAD (03.1-02 adds the three PHP workflows and the PHPUnit PASS count)
- **After every wave:** the same-wave Gate W waits overlap (one CI cycle per wave, owner CI batching); Playwright is NOT awaited per plan
- **Pre-release browser check:** 03.1-07 waits for Playwright Tests on its HEAD (covers the weekend, look and layering specs, and zoom when already pushed)
- **Before `/gsd-verify-work`:** all ten workflows green for the release sha R (Fork - Build image, NPM Build, NPM Format Check, NPM Lint, NPM Test Unit, NPM Typecheck, PHP Linting, PHPUnit Tests, Playwright Tests, Static code analysis (PHPStan)) and Microsoft365 PASS ≥ 75
- **Max feedback latency:** JS 60 s; CI one cycle (~10 min); browser one Playwright run (~60 min)
