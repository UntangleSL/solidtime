# Phase 3.1 Plan 01: Weekend visibility, Switch primitive, ledger rows Summary

A persisted "Show weekends" switch (first row of the calendar settings popover) hides Saturday and Sunday from the week view for any week start, while the fetched range stays the whole week; every stored settings value now passes through `sanitizeCalendarSettings` on read.

## What was built

- `calendarSettings.ts`: optional `showWeekends`, `SNAP_MINUTE_OPTIONS` (1, 5, 10, 15, 30, 60), `SLOT_MINUTE_OPTIONS` (5, 10, 15, 30, 60), `DEFAULT_CALENDAR_SETTINGS` (`Required<CalendarSettings>`), and a pure `sanitizeCalendarSettings(raw: unknown)`: non-objects and arrays give the defaults; snap/slot must be in their option lists (else 15); `startHour` integer 0..23, `endHour` integer 1..24, both reset to 0/24 when `startHour >= endHour`; `showWeekends` kept only when boolean (else true); unknown keys dropped.
- `useCalendarNavigation.ts`: optional `showWeekends?: () => boolean`; `weekDays` (unchanged logic) drives `emitDatesChange`; `viewDays` filters out `day()` 0/6 only in week view when the getter returns false; `rangeLabel` follows `viewDays`; an `initialDate` on a hidden weekend day starts in `timeGridDay`.
- `TimeEntryCalendar.vue`: defaults `{ ...DEFAULT_CALENDAR_SETTINGS }`, `mergeDefaults: (stored, defaults) => sanitizeCalendarSettings({ ...defaults, ...stored })`, and the `showWeekends` getter passed to the navigation. The deep settings watch is untouched (03.1-06 narrows it).
- `packages/ui/src/switch/`: package-local reka Switch, identical to `resources/js/Components/ui/switch` except `cn` comes from `../utils/cn`. Not added to the package barrel.
- `CalendarSettingsPopover.vue`: first row "Show weekends" + Switch (`id="calendar-weekends"`, `data-testid="calendar-weekends-switch"`) + `FieldDescription` "Applies to the week view." (`text-xs`); existing four fields unchanged.
- Tests: `useCalendarNavigation.test.ts` (7 cases: monday/sunday/saturday/wednesday week starts, missing/true getter, reactive flip, day view, deep link, range label), `calendarSettings.test.ts` (8 cases), `CalendarSettingsPopover.test.ts` (6 cases), `e2e/calendar-view-options.spec.ts` (5 Playwright tests, listed locally; CI runs them).
- Ledger: title mentions Phase 3.1; rows for `calendarSettings.ts` and `useCalendarNavigation.ts`; extended `CalendarSettingsPopover.vue` and `TimeEntryCalendar.vue` rows; new core files (switch, three Vitest files); fork-owned `e2e/calendar-view-options.spec.ts`.
