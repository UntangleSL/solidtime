## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| solidtime -> login.microsoftonline.com / graph.microsoft.com | Outbound HTTPS with the client secret and authorization code |
| Entra -> /auth/microsoft/callback | code and state arrive from the browser and are untrusted until validated |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-07 | Tampering | callback (login CSRF / code injection) | high | mitigate | Socialite state in session (hash_equals, single use) + PKCE S256 code_verifier; stateless mode forbidden (acceptance grep) |
| T-02-08 | Information disclosure | provider instance under Octane | high | mitigate | New Provider per call, container bind (not singleton/scoped), no Socialite manager; two-sequential-authentications test |
| T-02-09 | Spoofing | id_token | high | mitigate | Driver validates signature against tenant JWKS, iss and exp; unknown-key test; tid/aud asserted again by MicrosoftIdentityGuard |
| T-02-10 | Information disclosure | exception/log text | high | mitigate | Only the AADSTS code leaves the gateway; no exception message reads (acceptance grep); fixed reason values; the gateway never logs |
