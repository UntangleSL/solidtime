## Toolchain, push protocol and CI gates (identical in every Phase 2 plan)

The host has no system PHP or Docker. Shell state does not persist between Bash calls, so start every Bash call that runs PHP, Composer or a CI gate with:

```bash
export PHP_TOOLCHAIN_DIR="${PHP_TOOLCHAIN_DIR:-C:/Users/JuanHerrero/.local/solidtime-php-toolchain}"
export PHP_BIN="$PHP_TOOLCHAIN_DIR/phprun/php.exe"        # portable PHP 8.3.36 NTS (pdo_pgsql, intl, sodium, openssl, ...)

export COMPOSER_HOME="$PHP_TOOLCHAIN_DIR/composer-home"
export M365_LOG_DIR="$PHP_TOOLCHAIN_DIR/ci-logs" && mkdir -p "$M365_LOG_DIR"
```

Toolchain check (the `<precondition>` of each plan's first PHP-running task): `test -x "$PHP_BIN" && "$PHP_BIN" -v | grep -q "PHP 8.3" && "$PHP_BIN" "$COMPOSER_PHAR" --version --no-ansi | grep -q "Composer version 2" || { echo "toolchain missing: see 02-RESEARCH Environment"; exit 1; }`. When it prints that line, halt and report it: re-installing a PHP binary needs owner awareness (02-RESEARCH.md "Environment Availability" holds the SHA-256 of the archive).

PHPUnit is NOT run locally (needs PostgreSQL). It runs in CI on every push to `feature/m365-integration` (workflow "PHPUnit Tests", Postgres 15/16/17 matrix). Paths under `vendor/` named in read_first are installed dependency sources (git-ignored, present after `composer install` in 02-01 Task 1 and `composer require` in 02-04 Task 1); they are read-only references and are never modified or committed.

Push protocol (same-wave executors push to the same branch): `git pull --rebase origin feature/m365-integration && git push origin HEAD:feature/m365-integration`. If the push is rejected as non-fast-forward, run the same two commands once more; a second rejection or a rebase conflict stops the plan and is reported. `.planning/` writes are orchestrator-owned in sequential mode, so they never race between executors.

After pushing, wait for CI WITHOUT foreground sleep: start this loop with `run_in_background` (or ask the orchestrator) and continue when it exits:

```bash
SHA=$(git rev-parse HEAD); until [ "$(gh run list --commit "$SHA" --limit 40 --json workflowName,status --jq '[.[] | select(.workflowName=="PHPUnit Tests" or .workflowName=="PHP Linting" or .workflowName=="Static code analysis (PHPStan)" or .workflowName=="NPM Test Unit")] | (length==4 and all(.status=="completed"))')" = "true" ]; do sleep 30; done
```
