## Toolchain, push protocol and CI gates (identical in every Phase 2 plan)

The host has no system PHP or Docker. Shell state does not persist between Bash calls, so start every Bash call that runs PHP, Composer or a CI gate with:

```bash
export PHP_TOOLCHAIN_DIR="${PHP_TOOLCHAIN_DIR:-C:/Users/JuanHerrero/.local/solidtime-php-toolchain}"
export PHP_BIN="$PHP_TOOLCHAIN_DIR/phprun/php.exe"        # portable PHP 8.3.36 NTS
export COMPOSER_PHAR="$PHP_TOOLCHAIN_DIR/composer.phar"   # Composer 2.10.3

export M365_LOG_DIR="$PHP_TOOLCHAIN_DIR/ci-logs" && mkdir -p "$M365_LOG_DIR"
```

Toolchain check (needed only if `vendor/` must be re-installed): `test -x "$PHP_BIN" && "$PHP_BIN" -v | grep -q "PHP 8.3" && "$PHP_BIN" "$COMPOSER_PHAR" --version --no-ansi | grep -q "Composer version 2" || { echo "toolchain missing: see 02-RESEARCH Environment"; exit 1; }`. Push protocol: `git pull --rebase origin feature/m365-integration && git push origin HEAD:feature/m365-integration`. If the push is rejected as non-fast-forward, run the same two commands once more; a second rejection or a rebase conflict stops the plan and is reported. `.planning/` writes are orchestrator-owned in sequential mode.

CI wait (no foreground sleep; start with `run_in_background` and continue when it exits):

