Push protocol (same-wave executors push to the same branch): `git pull --rebase origin feature/m365-integration && git push origin HEAD:feature/m365-integration`. If the push is rejected as non-fast-forward, run the same two commands once more; a second rejection or a rebase conflict stops the plan and is reported. `.planning/` writes are orchestrator-owned in sequential mode.

CI wait (no foreground sleep; start with `run_in_background` and continue when it exits):

```bash
SHA=$(git rev-parse HEAD); until [ "$(gh run list --commit "$SHA" --limit 40 --json workflowName,status --jq '[.[] | select(.workflowName=="PHPUnit Tests" or .workflowName=="PHP Linting" or .workflowName=="Static code analysis (PHPStan)" or .workflowName=="NPM Test Unit")] | (length==4 and all(.status=="completed"))')" = "true" ]; do sleep 30; done
```
