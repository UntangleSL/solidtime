## Phase Goal

**As a** team member tracking time, **I want to** see my Outlook meetings as suggestions in the solidtime calendar, **so that** I can see which meetings still need logging without switching to Outlook.

<objective>
Backend tracer of Phase 3, Graph-to-cache half: a connected user's Outlook meetings for a range travel from Microsoft Graph `calendarView` (literal URL, combined `Prefer` header on every page, `nextLink` followed verbatim with a host check) through the fail-closed eligibility filter into the new `outlook_meetings` cache, written in UTC. The research decision "database cache" (03-RESEARCH Decision 1) is built for keeps here; the HTTP endpoints follow in 03-02, refresh in 03-03, resilience in 03-04.

Purpose: SYNC-03 (eligibility) and SYNC-04 (UTC storage) proven against the real Phase 1 fixtures, and the read-only Graph fetch of SYNC-01, before any endpoint or UI exists.
Output: two tables, two models, the Graph client, eligibility, token seam, sync service, fixture test support and OutlookMeetingSyncTest green in CI.

Assumption-delta decision (recorded for the phase): no-change. The phrase "another user's meetings" is privacy wording; the identity model (user + tenant-pinned Microsoft account, one primary calendar) is unchanged; shared calendars stay v2 SYNC2-02.
</objective>
