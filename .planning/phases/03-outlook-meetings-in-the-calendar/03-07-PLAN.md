## Phase Goal

**As a** team member tracking time, **I want to** see my Outlook meetings as suggestions in the solidtime calendar, **so that** I can see which meetings still need logging without switching to Outlook.

<objective>
Close the privacy edges of the meeting overlay: meetings are visible only to their owner for every role (CAL-03, D-16), an impersonating admin can neither read the user's meetings nor make Graph calls with the user's token (D-22, pulled forward from SEC-04; Phase 7 still owns its full verification), and Disconnect purges the cached meetings, sync windows and dismissals (D-21). The plan ends with a leak matrix over logs, props, audits and admin surfaces, and a proof that no Phase 3 path touches time entries.

Purpose: the owner's "privacy first" decisions hold end to end before release.
Output: GraphAccessGuard choke point, impersonation handling in token service / sync / controller / prop, disconnect purge, OutlookMeetingPrivacyTest green in CI.

Canon items (not minted as prohibitions, covered by /gsd-secure-phase and their own plans' tests): token and secret leakage in logs (03-02), bearer token to a foreign host (03-01), XSS through meeting text and links (03-04, 03-06).
</objective>
