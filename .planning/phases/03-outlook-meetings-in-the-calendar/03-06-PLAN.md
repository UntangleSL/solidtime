## Phase Goal

**As a** team member tracking time, **I want to** see my Outlook meetings as suggestions in the solidtime calendar, **so that** I can see which meetings still need logging without switching to Outlook.

<objective>
Wire the ghost layer (03-05) to the backend (03-02..03-04): the calendar page gets its Outlook state, URLs and the full copy contract from the shared prop, reads the cached meetings for the visible week after the time entries, triggers a debounced single-flight sync, and renders the ghosts in their lane. A Playwright spec proves in a real browser that ghosts never disturb entries or totals and that a ghost exactly overlapping an entry stays reachable (D-01).

Purpose: the phase goal becomes visible to the user: opening the calendar shows the Outlook meetings (SYNC-01, SYNC-02, CAL-01, CAL-02).
Output: calendar shared prop and copy, API helpers, query composable with test hook, Calendar.vue wiring, Vitest and Playwright proof; CI green.
</objective>
