## Phase Goal

**As a** team member tracking time, **I want to** see my Outlook meetings as suggestions in the solidtime calendar, **so that** I can see which meetings still need logging without switching to Outlook.

<objective>
The connection half of the toolbar cluster (03-UI-SPEC section 3, D-09, D-10): "Connect Microsoft 365" for users without a usable connection and "Reconnect Microsoft" when the token cannot be refreshed, both starting the Phase 2 connect flow and returning to the calendar through a strictly allow-listed, server-side return target, with the outcome shown as a notification on the calendar.

Purpose: SEC-02 ends in a prompt the user can act on instead of an error.
Output: connect return target in the fork auth controller, connect URL and notice in the calendar prop, Connect/Reconnect buttons, PHP and Vitest tests; CI green.
</objective>
