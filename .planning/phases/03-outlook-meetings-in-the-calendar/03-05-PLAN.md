## Phase Goal

**As a** team member tracking time, **I want to** see my Outlook meetings as suggestions in the solidtime calendar, **so that** I can see which meetings still need logging without switching to Outlook.

<objective>
The Outlook control cluster of the calendar toolbar (03-UI-SPEC section 3 and section 5): a "Sync Outlook" button with cooldown and back-off awareness, a quiet status line (syncing, last synced, empty, unavailable, no mailbox), and the connection-state variants, "Connect Microsoft 365" for users without a connection and "Reconnect Microsoft" when the token cannot be refreshed, both of which start the Phase 2 connect flow and return to the calendar.

Purpose: SYNC-02 (manual Sync without hammering Graph), SYNC-05 (non-blocking status) and SEC-02 (reconnect prompt instead of an error) become usable from the calendar.
Output: toolbar slot seam, control component, status helper, composable extensions, server-side copy, connect return target, Vitest and PHP tests; CI green.
</objective>
