---

## Sampling Rate

- **After every JS task:** `npx vitest run <touched tests>` + eslint + prettier on the touched files (Gate F at the end of each plan adds `npm run type-check` and `npx tsc --noEmit`)
- **After every PHP task:** Pint on the touched paths + full-app PHPStan (Gate P)
- **After every wave:** the wave anchor (03.2-03, 03.2-07, 03.2-08) waits once for the eight workflows on the HEAD containing the whole wave (Gate W) and counts Appearance PHPUnit classes x 3 Postgres jobs (Gate B)
- **Before `/gsd-verify-work`:** all ten workflows green for the release sha (03.2-09), including `e2e/appearance.spec.ts` in Playwright and Microsoft365 PASS >= 75 (no regression)
- **Max feedback latency:** JS 60 s; PHP one CI cycle (~10 min) per wave
