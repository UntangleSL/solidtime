## Shell setup, push protocol and gates

Start every Bash call that runs a CI gate or writes a log with:

```bash
export PHP_TOOLCHAIN_DIR="${PHP_TOOLCHAIN_DIR:-C:/Users/JuanHerrero/.local/solidtime-php-toolchain}"
export M365_LOG_DIR="$PHP_TOOLCHAIN_DIR/ci-logs" && mkdir -p "$M365_LOG_DIR"
```

This plan runs no PHP locally (only `gh`, `curl`, `git` and the node docs gates). Push protocol, explicit `git add <paths>`, hooks on, commit subjects scoped `(03.2-09)`, trailer `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`, never read `.env` files and never print secrets, exactly as in 03.2-01-PLAN.md. Dokploy is changed ONLY by the orchestrator via MCP after explicit owner approval; the executor never sees or handles secret values. Images are pinned by `sha-<7>` tag because Dokploy does not re-pull a reused tag (02-11 key decision). Phase 3.1 shares the branch: if 3.1 was released first, rebase onto it; R always includes whatever is on the branch.

Background CI wait for the release gate (Playwright runs 8 shards, up to 60 min):

```bash
SHA=$(git rev-parse HEAD); until [ "$(gh run list --commit "$SHA" --limit 40 --json workflowName,status --jq '[.[] | select(.workflowName=="PHPUnit Tests" or .workflowName=="PHP Linting" or .workflowName=="Static code analysis (PHPStan)" or .workflowName=="NPM Test Unit" or .workflowName=="NPM Lint" or .workflowName=="NPM Typecheck" or .workflowName=="NPM Format Check" or .workflowName=="NPM Build" or .workflowName=="Playwright Tests" or .workflowName=="Fork - Build image")] | (length>=10 and all(.status=="completed"))')" = "true" ]; do sleep 60; done
```
