## Phase Goal

As Untangle, I want solidtime to look like our own tool by default and let each user tune it, so that the app feels branded and comfortable to use.

<objective>
Create the fork module `app/Appearance/` (orchestrator resolution 3): a side table `user_appearance_settings`, a session route `PUT /user/appearance` that stores the signed-in user's theme and accent, a web-group middleware that shares an `appearance` prop with every Inertia page, the request-memoised resolver that the pre-paint partial (03.2-04) will call, the English and Spanish copy for the whole phase, and the TypeScript contract of the prop.

Purpose: BRAND-02 persistence per user across devices (D-05) without touching `User.php`, `ShareInertiaData.php`, `/api/v1` or `openapi.json` (D-08).
Output: module skeleton, one migration, one route, one prop, two lang files, one TS contract module, PHPUnit and Vitest tests.
</objective>
