</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser -> POST/DELETE /organizations/{organization}/icon | Authenticated session request with a client-supplied organization id and file content |
| Server -> public disk | Uploaded bytes become a publicly served file |
| Server -> every Inertia page | Icon URLs of the user's organizations are shared |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03.2-13 | Elevation of privilege | OrganizationIconController | high | mitigate | organizations:update via PermissionStore::has (owner and admin only); permission matrix test covers manager, employee, non-member, guest |
| T-03.2-14 | Tampering (cross-organization) | route binding | high | mitigate | Permission evaluated on the bound organization and requires membership; whereUuid; unknown and non-uuid ids are 404 |
| T-03.2-15 | Tampering (malicious file: SVG script, polyglot) | OrganizationIconRequest | high | mitigate | Content-sniffed PNG/JPEG only (Base64ImageRule), extension derived from the sniffed MIME, uuid filename (no client-controlled name), dimension parse must succeed; served only through img tags |
| T-03.2-16 | Denial of service | upload route | medium | mitigate | throttle:20,1 per user; 1 MiB decoded cap; 32-1024 px per side bounds decode cost |
| T-03.2-17 | Information disclosure | appearance.org_icons | medium | mitigate | Map limited to the signed-in user's organizations (test_prop_lists_only_the_users_organizations); guests get an empty map |
| T-03.2-18 | Information disclosure (orphaned files) | organization deletion | low | mitigate | BeforeOrganizationDeletion listener deletes the file after commit; FK cascade removes the row; test covers it |
