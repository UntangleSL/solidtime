## Phase Goal

**As a** team member who already logged a meeting, **I want to** be told when Outlook moves or cancels it and choose what happens to my entry, **so that** my logged hours are never changed behind my back.

<objective>
Make the two risky pieces of the tracer safe in every context they run in: the in-process core update (HTTP request, queued job, upstream drift) and the applier (stale observations, core refusals, releases, lock contention). The tracer proved the happy path; this plan proves the failure paths so that nothing ever changes an entry when it should not.

Purpose: OSYNC-02 "never changed unless safe" (D-04, D-07, D-12) for both entry points (interactive sync, daily job).
Output: hardened `CoreTimeEntryUpdater` and `OutOfSyncApplier`, a local contract test and two CI feature test classes.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Queued job -> core controller | Core code runs without a request; the fork supplies the acting user |
| Concurrent writers -> one entry | User edits, interactive sync and the daily job can touch the same entry |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-06-11 | Elevation of privilege | Auth guard left set after a job update | high | mitigate | setUser only when no user is authenticated, forgetUser in finally; tests assert Auth::user() null after success and after a core exception |
| T-06-12 | Tampering (integrity) | Stale observation rewinding an entry | high | mitigate | last_checked_at guard under row locks; out-of-order test |
| T-06-13 | Tampering | Blocked organization or overlap bypass | medium | mitigate | Updater replicates check-organization-blocked; core's overlap check runs; refusal -> flag, tests for both |
| T-06-14 | Repudiation | Entry changes without an actor | low | mitigate | Changes go through core update, audited with the link's user as actor (owen-it auditing reads Auth::user()) |
| T-06-SC | Tampering | npm/pip/cargo/Composer installs | high | mitigate | No package installs |
</threat_model>
