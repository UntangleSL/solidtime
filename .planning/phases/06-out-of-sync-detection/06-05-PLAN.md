## Phase Goal

**As a** team member who already logged a meeting, **I want to** be told when Outlook moves or cancels it and choose what happens to my entry, **so that** my logged hours are never changed behind my back.

<objective>

The same plan proves 06-01's migration in a database and aligns the project docs with the owner's D-12 exception.

Purpose: OSYNC-02 first bullet (auto adjust) end to end. Later plans add applier safety (06-08), lookups for absent meetings (06-09), the actions (06-10) and the daily job (06-15).

</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Microsoft Graph -> fork sync | Event times and flags arrive from an external service and decide entry changes |
| Fork -> core time entries | The fork changes core rows in-process, outside core's HTTP middleware |
| Sync request -> other users' rows | One table holds every user's links |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-06-01 | Tampering (integrity) | Auto adjust of time entries | high | mitigate | Only for not-started meetings whose entry equals the snapshot (pure rules, 06-01 matrix); only through core `TimeEntryController::update` (permissions, overlap, recalculation); core failure -> flag, never a forced write; no delete path exists (test) |
| T-06-02 | Elevation of privilege | CoreTimeEntryUpdater acting user | high | mitigate | Uses the session user only when it is the link's user; any other authenticated user -> LogicException; organization = the entry's; blocked organization checked like core's middleware |
| T-06-04 | Tampering | Partial or failed traversal | medium | mitigate | Sightings applied only after a complete, failure-free traversal (D-07); test with a page-capped traversal |
| T-06-05 | Information disclosure | Cross-user links | high | mitigate | OutOfSyncScope filters by the user and by `time_entries.user_id = links.user_id`; the applier re-reads link and entry under row locks and skips foreign entries |
| T-06-SC | Tampering | npm/pip/cargo/Composer installs | high | mitigate | No package installs |
</threat_model>
