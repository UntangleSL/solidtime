## Phase Goal

**As** Untangle management, **I want** each client project to carry its contract terms (hours and money sold, renewing on a schedule), the team's billable time to consume them, and a view of profitability and team chargeability, **so that** we see per month, per project, per client and per person whether we are on track to the contract close.

<objective>
Enforce D-05 on the server for every write path at once: a work entry saved on a billable project is billable, with its rate recomputed, through one fork-side `TimeEntry::saving` listener. Existing entries are never silently rewritten: an edit that does not touch project, billable flag or type leaves a legacy entry alone, and a read-only command reports the legacy non-billable time on billable projects. The two upstream browser tests that asserted the opposite behaviour are updated to assert the fork rule.

Purpose: BUDG-03 second half ("on a billable project every entry is billable") with the D-05 planning decision for existing data (report, never rewrite).
Output: one listener, one read-only query, one command, two feature test classes, two updated upstream e2e tests.
</objective>
